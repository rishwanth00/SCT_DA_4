Marketing Campaign Analysis Dashboard

Project Overview

This project is part of the SkillCraft Technology Data Analytics Internship (Task 04). The objective was to perform Exploratory Data Analysis (EDA) on a marketing campaign dataset and generate business insights using Power BI.

Tools Used

- Power BI
- Microsoft Excel
- Data Cleaning & Transformation
- Data Visualization

Key Metrics

- Total Customers: 2,240
- Average Income: 52.25K
- Total Spending: 1M
- Campaign Responses: 333
- Response Rate: 15.03%

Dashboard Visualizations

- Total Spending by Education
- Total Spending by Marital Status
- Campaign Responses by Age Group
- Total Spending by Age Group
- Interactive Filters for Education and Marital Status

Key Insights

- Graduation-level customers contribute the highest spending.
- Married customers represent the largest spending segment.
- Customers aged 60+ generate the highest spending.
- Campaign performance varies across age groups.
- The overall response rate is 15.03%.

Recommendations

- Focus marketing efforts on high-spending customer segments.
- Increase budget allocation for customers aged 50+.
- Create personalized campaigns for married customers.
- Improve engagement strategies for lower-response groups.

Conclusion

The analysis identified valuable customer segments and spending patterns that can help improve marketing effectiveness and increase return on investment (ROI).
